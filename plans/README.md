# Improvement Plans — growth.site

Generated by the `improve` advisory workflow (read-only audit → vetted findings → executable plans).
Base commit: `7f9169e1a64a3a65abbd8798b527cf481f294635` (branch `robkkan/indianapolis`).

These plans are self-contained. Each can be executed independently by an agent with no prior
context. Execute in priority order where practical; dependencies are noted per-plan.

## How to use

1. Pick the highest-priority unblocked plan.
2. Read it top to bottom — it contains the current-state excerpts, exact steps, and verification gates.
3. Implement, then run the verification gate. Do not mark done until the gate passes.
4. Re-run `npm run build` after any plan that touches pages, metadata, or images.

## Notable cross-cutting root cause

Most SEO **and** a large share of the performance findings share one root cause: **every route is a
top-level `"use client"` component.** That blocks the Next.js Metadata API (003) and ships static
article markup as client JS. Plan 003 is the structural fix; 002 delivers the SEO wins that don't
require it first.
